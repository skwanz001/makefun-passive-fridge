One funny passive-aggressive note a smart fridge leaves for its owner — a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen.

The note:

> Inventory update: the yogurt expired Tuesday. You ate it Wednesday. I have filed this under 'evidence'.

## Run it

```sh
python3 main.py
```

Writes the note to `/output/entry.txt` (103 characters, one line, UTF-8, standard library only).
